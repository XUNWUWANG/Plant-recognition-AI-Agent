## 3. 分层与依赖方向

当前依赖(允许方向):

```text
app ──► plant.ui ──► plant.orchestrator ──► advice ──► retrieval.rag ──► retrieval.router
                                 │                        └──► retrieval.retrievers
                                 ├──► vision.api ──► llm ──► config
                                 └──► vision.local ──► config
compare ──► tools(转发) ──► vision.*
```

规则:

1. 依赖只允许向下,禁止循环;
2. `retrieval.router` 只依赖 `retrievers.tokenize`,不依赖 `rag`;
3. `retrievers` 不依赖 `rag`;
4. `retrieval.settings` 只依赖根 `config.BASE_DIR`,产品层不读检索参数;
5. `retrieval.eval` 依赖检索模块,不被产品模块依赖;
6. `app` 只依赖 `plant.ui`,不再直接依赖业务模块(CR-003/007);
7. `tools.py` 只是转发壳,新代码直接依赖 `llm`/`vision`/`advice`;`compare.py` 保留 `tools` 导入(CR-006)。

## 4. 模块职责与公共接口

### 4.1 `config.py`

- 加载 `.env`(不覆盖已有环境变量);
- API:`DEEPSEEK_API_KEY`、`BASE_URL`、`MODEL`、`require_api_key()`;
- CV 路径:`DATA_DIR`、`TEST_DIR`、`CKPT`、`NUM_CLASSES`;
- 检索配置已迁出,见 `retrieval/settings.py`(CR-004)。

### 4.2 `retrieval/settings.py`

- 只依赖 `config.BASE_DIR`;
- 模型:`EMBED_MODEL`、`EMBED_FALLBACK`;
- 缓存:`EMBED_CACHE`、`CHUNKS_CACHE`;
- 知识库:`KB_DIR`;
- 评测:`EVAL_DIR`、`EVAL_DB`;
- 超参:`TOP_K`、`FUSE_TOP_N`、`RRF_K`、`COVERAGE_THRESHOLD`、`DENSE_COS_THRESHOLD`、`ANSWER_COS_THRESHOLD`、`CHUNK_MIN_LEN`;
- `rag.retrieve*` 内部保证 `topk ≥ TOP_K`,产品层不再传检索参数。

### 4.3 产品能力模块(`llm` / `vision` / `advice` / `tools`)

- `llm.py`:`get_client()` 懒加载 OpenAI 兼容客户端,无 Key 只在调用时报错;
- `vision/api.py`:`classify_plant`、`_image_to_data_url`、`_parse_json`(DeepSeek 多模态);
- `vision/local.py`:`classify_local`、`_load_local_model`(torch/torchvision 懒加载);
- `advice/service.py`:`plant_advice`(检索 + LLM)、`plant_advice_offline`(零 API 原文);
- `tools.py`:纯转发壳,仅 re-export 四个函数,无业务逻辑;`compare.py` 通过它保持兼容。

### 4.4 `plant/` 产品层

- `plant/orchestrator.py`:`agent_handle` 唯一编排入口(含计时与页脚)、`_identify`;
- `plant/render.py`:`FLOWER_LANG`、`_flower_lang`、`_conf_color`、`_render_advice`;
- `plant/ui.py`:`run` 回调、`build()`、`demo`、`launch()`、CSS 与前端 JS;
- 输出 Markdown;无图时标题为"养护问答";库外走 generic 提示;末尾输出"本次用时/路线"。

### 4.5 `app.py`

- 仅 `from plant.ui import demo, launch`;`python app.py` 调用 `launch()`;
- 界面实现全部在 `plant/ui.py`,端口仍为 `127.0.0.1:7860`。

### 4.6 `retrieval/rag.py`

公共接口:

| 函数 | 说明 |
|---|---|
| `get_chunks()` | 返回已解析的 chunks,供评测/统计 |
| `retrieve(query="", topk=None, plant_hint=None)` | 返回 `['## 植物 · 小节\n正文', ...]` |
| `retrieve_debug(query="", topk=None, plant_hint=None)` | 额外返回 route/retried/latency/coverage/top1_cos/results |
| `retrieve_hit(query="", topk=None, plant_hint=None)` | 返回 `(片段列表, 是否命中知识库)` |
| `naive_rank(query, topk=None)` | 原字面匹配排序(基线) |
| `naive_retrieve(query, topk=None)` | 基线片段列表 |

内部:

- `_load_chunks(force=False)`:kb_hash 校验 + `models/cache/chunks.json` 缓存;
- `_ensure_bm25()` / `_ensure_dense()` / `_ensure_names()`:懒构建;
- `_detect_plant(q)`:本名/别名/学名 → 植物本名;
- `_filter_plant(ranked, plant)`:实体约束;
- `_search(route, q, topk, plant=None)` / `_run(...)`:检索执行与回退;
- `_top1_text(ranked)`:覆盖率计算文本(含植物名/小节名);
- CLI:`python -m retrieval.rag --stats|--rebuild`。

### 4.7 `retrieval/retrievers.py`

- `tokenize(text) -> list[str]`:jieba + 停用词 + 标点过滤;
- `BM25Index(chunks)`:分词语料 + 汉字级补偿;`search(query, topk) -> [(id, score)]`;
- `DenseIndex(chunks, model_name=None, cache_path=None)`:优先 sentence-transformers,失败用 transformers 直载;查询按模型加 instruction;向量 L2 归一化;npz 缓存;
- `rrf_fuse(ranked_lists, k=60, topk=5) -> [(id, score)]`。

### 4.8 `retrieval/router.py`

- `collect_names(chunks) -> (all_names, primary_names)`;
- `content_tokens(query)` / `coverage(query, text)`;
- `decide(query, plant_hint, names, primary_names=None) -> route`;
- `should_retry(route, top1_text, query, top1_cos=None) -> route | None`;
- 纯函数,不依赖 `rag`。

### 4.9 `retrieval/eval.py`

- P1 主表配置:`P1:dense+filter`、`P1:hybrid+filter`、`P1:bm25+filter`、`P1:adaptive`、`P1:adaptive−filter`、`P1:adaptive−retry`;
- P2 辅表配置:`P2:naive`、`P2:bm25`、`P2:dense`、`P2:hybrid`、`P2:adaptive`(行为与数字保持改造前);
- 指标:Top-1 / Recall@5 / MRR(CR-010 起 Top-1 进入内存与 Markdown;`eval.db.top1_hit` 由 CR-012 落地);
- P1 实体:`case.plant_hint`,缺失时 `rag._detect_plant(query)`;纯检索组通过 `rag._search(..., plant)` 复用实体约束;
- `adaptive−filter` / `adaptive−retry` 在 `eval.py` 内组合现有路由与检索函数,不改产品代码;
- 路由效用:逐题比较 `P1:adaptive` 对 `P1:dense+filter`、`P1:hybrid+filter` 的 Top-1/Recall/MRR 差值,报告均值、中位数、胜/平/负(平局 1e-9);
- CLI:`python -m retrieval.eval [--configs 键或简写] [--cases ...] [--limit N] [--out ...] [--err ...] [--db ...]`;简写 `naive/bm25/dense/hybrid/adaptive` 映射到 P2;含 U+2212 的配置名同时接受 ASCII `-` 别名;
- `eval.db` 以 `eval_run.config = "P1:xxx"/"P2:xxx"` 区分协议,未改表结构。

### 4.10 `scripts/` 与 `tests/`

- `build_eval.py`:按模板生成候选题;`--blind-check` 校验盲题集(名称泄漏、重合 ≤8 字、related 存在、target_plant 唯一性);
- `run_app.cmd`:设置 `HF_HUB_OFFLINE=1` 后启动 `app.py`;
- `tests/`:路由决策/覆盖率、chunk 与 RRF、兼容性与库外闸门。

## 5. 关键流程

### 5.1 产品请求

```text
app.py / plant.ui.run
  └─ plant.orchestrator.agent_handle
       ├─ 有图 → orchestrator._identify(route)
       │        ├─ api  → vision.api.classify_plant → llm
       │        └─ local→ vision.local.classify_local
       └─ 建议
            ├─ api  → advice.service.plant_advice → retrieval.rag → llm
            └─ local→ advice.service.plant_advice_offline → retrieval.rag(零 API)
```

### 5.2 检索执行

```text
retrieve(query, topk, plant_hint)
  ├─ _ensure_names / decide(route)
  ├─ plant = plant_hint or _detect_plant(query)
  ├─ _search(route, q, topk, plant)
  │    ├─ bm25  → BM25Index.search(全库或本植物)
  │    ├─ dense → DenseIndex.search(全库或本植物)
  │    └─ hybrid→ 两路 Top-10 → RRF(k=60) → Top-5
  ├─ should_retry(...) → 必要时改跑 hybrid
  └─ 格式化 '## 植物 · 小节\n正文'
```

### 5.3 评测

```text
retrieval.eval
  ├─ load_cases(120)
  ├─ 每组 warm-up → 逐题检索并计时
  ├─ Recall@5 / MRR / 分类型 / 路由分布
  └─ 写 指标/retrieval/检索对比表.md、错误案例、eval.db
```

## 6. 数据与缓存生命周期

1. `kb/*.txt` → `_parse_kb()` → chunks(按植物+小节,去重,过滤短片段);
2. 源文件内容 sha1 → `kb_hash`;写入 `models/cache/chunks.json`;
3. `DenseIndex` 对 chunks 文本计算 sha1;与 npz 中 `kb_hash`/`ids`/`model` 一致则命中,否则重建并写 `models/cache/emb_qwen3_0.6b.npz`;
4. 修改知识库后:`python -m retrieval.rag --rebuild`(同时重建 chunks 与向量缓存);
5. 评测产物写入 `指标/retrieval/`,SQLite 追加 `eval_run`/`case_result`/`route_trace`;
6. `models/cache/` 与训练数据不提交,评测集 `data/eval/*.jsonl` 随仓库提供。

## 7. 运行与 CLI

所有命令必须在**项目根目录**执行(依赖根目录在 `sys.path`):

```bash
python app.py                       # 界面
scripts\run_app.cmd                 # 离线模式启动(已缓存模型)
python -m retrieval.rag --stats     # 分块统计
python -m retrieval.rag --rebuild   # 重建 chunks 与向量缓存
python -m retrieval.eval            # 五组评测
python -m unittest discover -s tests
```

环境变量:

- `DEEPSEEK_API_KEY`(`.env`);
- `HF_ENDPOINT`(镜像,可选);
- `HF_HUB_OFFLINE=1`(模型已缓存时推荐)。
