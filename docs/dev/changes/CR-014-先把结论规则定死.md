## 1. 变更原因

规则表第 5 条是“纯症状 → dense”，但**无过滤的** dense 在 symptom 上只有 0.438（bm25 0.675、hybrid 0.637），等于把最难的问法交给最弱的检索器。

注意区分两种场景：无植物名时 dense 很弱；一旦有植物名并启用实体过滤，`dense+filter` 反而是 P1 下最强（Top-1 / Recall@5 / MRR = 0.700 / 0.950 / 0.836）。因此不能笼统说“dense 差”，规则必须按“是否已知植物”分别判断。

盲症状集（CR-011）会第一次真正触发规则 5；如果不先把“什么结果算什么结论、要不要改规则”写死，跑完数据后必然出现“看结果再调规则”的争议。本 CR 的作用是**预注册**：在跑盲题之前，固定假设、指标、阈值与决策规则。

## 3. 预注册假设

题集：盲题 60 条（40 symptom + 20 multi）；P1 已知植物主表 110 道可答题。

**盲题（无植物名，实体过滤不生效）**

- **H1（主假设）**：盲题上，最佳无过滤基线（bm25 / dense / hybrid 三者中 Recall@5 最高者）比规则 `adaptive` 高 **≥ 0.05**；
- **H2（等价假设）**：差值严格落在 **(−0.05, 0.05)** 内；
- **H4（组件）**：仅在 40 条 symptom 子集上，`dense`（无过滤）是三者中最低的（multi 不参与 H4）。

**已知植物（P1 主表）**

- **H5（产品路线）**：满足任一条件即改产品默认路线：
  1. `dense+filter` 的 Recall@5 比 `adaptive` 高 **≥ 0.05**；
  2. `dense+filter` 在 Top-1 / Recall@5 / MRR 三项均不低于 `adaptive`，且中位延迟不高于 `adaptive`（Pareto 占优；延迟以 CR-012 固定口径为准）。
  否则视为等价，保留现规则并如实报告 dense+filter 点估计最高。

**Agentic（CR-009）**

- **H3**：盲题上 `agentic-full` 比“最佳无过滤基线”高 ≥ 0.05，且 P1 上不低于 `dense+filter`。

指标同时看 Top-1、Recall@5、MRR，均附 Wilson 95% 区间；比较用配对 bootstrap / McNemar（CR-012）。**决策以 Recall@5 为主，Top-1/MRR 作一致性检查。**

## 4. 决策规则（先写死，跑完直接套）

记差值 = `adaptive − 对应基线`；阈值首尾相接，覆盖所有差值。

**盲题（基线 = bm25/dense/hybrid 中 Recall@5 最高者，无过滤）**

| 盲题结果 | 决定 |
|---|---|
| 差值 ≤ **−0.05** | 改规则 5：纯症状改走盲题最佳基线（通常是 hybrid）；另立产品 CR |
| **−0.05 < 差值 < 0.05** | 保留规则 5；写“等价”，不写“路由更好” |
| 差值 ≥ **0.05** | 保留规则 5，并报告路由收益 |

**P1 已知植物（基线 = dense+filter）**

| P1 结果 | 决定 |
|---|---|
| 差值 ≤ **−0.05**，或 dense+filter 三项不低于 adaptive 且中位延迟不高于 adaptive（Pareto 占优） | 改产品默认路线：已知植物时走 dense+filter；另立产品 CR |
| **−0.05 < 差值 < 0.05** 且不满足占优条件 | 视为等价：保留现规则，但如实报告 dense+filter 点估计最高 |
| 差值 ≥ **0.05** | 保留现规则，并报告路由收益 |

> **诚实说明**：P1 已在 CR-010 跑完；H5 与“Pareto 占优”规则是基于 P1 实测的**事后判定**，不用于盲题预注册；盲题 H1/H2/H4 仍未被结果影响，仍须在盲题开跑前冻结。延迟以 CR-012 固定口径为准。

**Agentic 与组件**

| 结果 | 决定 |
|---|---|
| 盲题上 agentic-full 比最佳无过滤基线高 ≥ 0.05，且 P1 不低于 dense+filter | 按 CR-009 开启（仍默认关闭,由开关控制） |
| 任一条件不满足 | 保持关闭，记录负结果，不进入主结论 |
| dense 路线重试率 > 50% 且重试后仍低于盲题最佳基线 | 判定规则 5 不成立，按盲题第一行处理 |

> 决策口径:产品/规则决策依据**点估计**;置信区间只作不确定性参考,不用于宣称“统计显著”。若点估计与区间结论冲突,按点估计执行,并在局限中说明。

**禁止**：看完结果再改阈值、改题、改指标定义；任何偏离必须另立 CR 并注明原因。

## 5. 样本量与统计口径

- 盲题 60 条（全部用于 H1/H2/H3）；H4 只用其中 40 条 symptom；
- P1 主表 110 道可答题（120 扣除 10 条 unanswerable）；unanswerable 扩展 30 条；
- 60 条时比例指标 95% 区间约 ±0.12（p≈0.7），P1 的 110 条约 ±0.06；均定位为**可行性证据**；
- 不宣称“统计显著”，只报点估计、区间与配对差值；
- 所有数字必须来自 `指标/retrieval/` 产物与固定 commit，不手工抄。
