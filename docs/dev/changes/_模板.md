# CR 模板

> 命名规则:
> - **文件名**可以用大白话,方便快速识别;
> - **文档内标题**必须写正式名称,并在下方附一行大白话别名;
> - 一个 CR 只做一件可验收的变更;跨模块的大改拆成多个 CR。
>
> 标题写法:
> `# CR-xxx 正式名称`  
> `> 文件名(大白话):……`

（为什么改:新需求 / 缺陷 / 指标不达标 / 架构调整）

- 数据/缓存:
- 文档:

（做什么;明确"不做"的边界,防止 scope creep）

- 命令:(如 `python -m unittest discover -s tests`)
- 指标:(如 Recall@5 ≥ x)

（如何撤回:git revert / 关闭开关 / 重新生成缓存）
