## 3. 方案要点

### 3.1 文档一致性

- 任务书 §10 交付物：`agent.py` → `plant/orchestrator.py`；补 `vision/`、`advice/`、`llm.py`、`agentic/`（规划中）、`data/eval/blind_queries.jsonl`（规划中）；
- 测试数量、命令、产物路径与当前代码对齐；
- README 指标注记补充“实体过滤是主要增益”的说明。

### 3.2 手工场景留档

用 3–5 张真实植物图片验证：

| # | 场景 | 证据 |
|---|---|---|
| 1 | 纯图片 + 本地路线 | 截图 + 输出 Markdown |
| 2 | 图片 + 追问 | 截图 + 输出 |
| 6 | 离线路线零 API | 网络/日志说明 + 输出 |

若暂时没有图片，明确标记“阻塞”，不得勾选。

### 3.3 验收记录

新增 `指标/retrieval/验收记录.md`，每次验收记录：

- 日期、git commit；
- `python -m unittest discover -s tests` 结果；
- `python -m retrieval.eval` 关键指标；
- 产物的存在性核对：盲症状对比表、agentic 对比、阈值敏感性、延迟对比、库外问题表；
- 手工场景结果与截图路径；
- 环境（Python / torch / transformers / sentence-transformers / hub）。

### 3.4 可复现性

- 在 `requirements.txt` 钉主版本或在 `constraints.txt` 固化实测组合
  （当前：torch 2.15.0+cpu、torchvision 0.29.2+cpu、transformers 5.24.1、
  sentence-transformers 6.3.0、huggingface-hub 1.33.0）；
- 记录嵌入模型 revision，或提供“本地模型目录”加载方式；
- README/架构说明写清 `HF_HUB_OFFLINE=1`、`HF_ENDPOINT` 与首次下载步骤。
