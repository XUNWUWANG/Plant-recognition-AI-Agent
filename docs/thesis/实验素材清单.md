## 二、当前可引用的基线(旧协议)

| 配置 | Recall@5 | MRR | Top-1 |
|---|---|---|---|
| naive | 0.682 | 0.433 | 0.245 |
| bm25 | 0.691 | 0.646 | 0.518 |
| dense | 0.518 | 0.445 | 0.318 |
| hybrid | 0.691 | 0.675 | 0.555 |
| adaptive | 0.927 | 0.804 | 0.655 |

公平对照实测(P1,括号内为 Top-1 / Recall@5 / MRR):**dense+filter 0.700 / 0.950 / 0.836(最强)**;hybrid+filter 0.682 / 0.932 / 0.824;bm25+filter 0.555 / 0.868 / 0.722。

> 注明:以上为旧评测协议下的原始五组 + 新复算的 P1 对照;CR-010 重跑后，论文只用新表，不混用。

## 三、必须主动写进“局限”的点

- 主表 110 道可答题、盲题 60 条、unanswerable 40 条，样本量只能支撑可行性结论；
- 知识库仅 20 种植物、140 chunks，结论不外推到开放域；
- CPU 上 dense 约 0.5 s/题，延迟结论依赖硬件；
- api 路线依赖外部模型，Agentic 评测为“录制 + 回放”，不是在线可复现；
- 2026-11-25 实测的依赖组合尚未长期验证。
