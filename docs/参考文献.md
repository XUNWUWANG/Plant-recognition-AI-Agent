## 三、逐条要点（引用时别写错）

**1. Adaptive-RAG** — 核心是训练一个小分类器判断问题复杂度，再选择"不检索 / 单步检索 / 多步检索"。你的"特征规则路由"是对它的**工程简化**，答辩时要主动说清差异，别说成"复现"。
作者：Soyeong Jeong, Jinheon Baek, Sukmin Cho, Sung Ju Hwang, Jong C. Park（KAIST）。DOI 与页码见上。

**2. Self-RAG** — 用反思标记让模型决定是否检索、结果是否相关。你的路由"要不要检索/哪条路"思想与此一脉相承，但实现远为简化。

**3. CRAG** — 原论文（arXiv v1-v3）用 T5-large 训练的轻量评估器，把检索结果分为 Correct / Incorrect / Ambiguous 并触发不同动作（知识精炼 / 网络搜索）。**注意**：后来有扩展版把 CRAG 描述为"自主 agent"；你引用时按 arXiv 原文口径说"检索后评估与纠错"，不要引用扩展版的夸张表述。

**4. RRF** — 原文明确：`RRFscore(d) = Σ 1/(k + r(d))`，`k=60` 是预实验选定、后续验证未改。你自己的文里写 `1/(k+rank)`、`k=60` 完全正确。

**5. BM25** — 引用它来支撑"BM25 是经典且有效的检索模型"，`k1`/`b` 的语义也可从这篇找依据。

**6. RAG** — 引用它定义 RAG 的基本思想（参数化 + 非参数化记忆）。注意它指的是"用稠密向量索引检索 + seq2seq 生成"的原始架构，与现在的工程化 RAG 不完全等同。

**7. MTEB** — 用于说明 embedding 选型有公开基准。**页码有出入**：DBLP/ACL 记为 2006–2029，另有来源记 2014–2037；答辩引用时以 ACL Anthology 正式版为准，或只写"EACL 2023"不写页码。

**8. Qwen3 Embedding** — 支撑"选 Qwen3-Embedding-0.6B"的合理性：论文给出 0.6B/4B/8B 三档，且说明模型支持 instruction、Matryoshka 表示。你可以引用它解释"为什么查询加 instruction"。

**9. 中文那篇（重要）** — 已核实为真实文献：作者卞佳兴（中国电子科技集团有限公司），《无线互联科技》2026 年第 12 期，第 79–82 页，共 4 页；CNKI 编号 `WXHK202612017`。
文中报告：35 份公开制度文件、64 个条款级片段、328 题评测集；混合检索 **F1=0.324、MRR=0.781**；在 Top-k=3、τ=0.4 时**综合正确率 96.9%**。
**引用注意**：
- `F1=0.324` 与 `综合正确率 96.9%` 是**两个不同指标**，不能混着说，也不能拿来暗示"你的系统也能到 96.9%"。
- 它的价值是"中文知识库问答里，BM25+向量+重排/置信拒答的工程路线已被验证"，不是"证明你的方案一定更好"。
- 期号为 2026(12)，但 CNKI 已上线可查；给老师时最好附 CNKI 链接或截图。

## 四、如何自己复核（三条铁律）

1. **先看有没有 DOI / arXiv ID / 数据库收录号**。没有的，先当成"待核实"，不要写进论文。
2. **至少两个独立来源一致**才算通过。英文：DBLP + ACL Anthology/OpenReview/ACM DL 任二；中文：CNKI + 维普/万方任二。
3. **引用前打开原文，确认它真的说了你要引的那句话**。只看摘要/二手转述就引用，是翻车高发区。

复核入口：
- 英文文献：https://dblp.org 、https://aclanthology.org 、https://openreview.net 、https://dl.acm.org
- arXiv：https://arxiv.org/abs/&lt;ID&gt;（你所在网络若被拦，用 `export.arxiv.org` 或 Semantic Scholar 镜像）
- 中文文献：https://www.cnki.net 、https://www.cqvip.com 、https://www.wanfangdata.com.cn

## 五、明确"不要引用"的内容

| 内容 | 原因 |
|---|---|
| 网上流传的"纯向量 72% / 纯 BM25 65% / 混合 91%""Hit@1 67%→100%" | 查不到原始出处，属于论坛转述；不能作为你的实验依据 |
| 腾讯云那篇教程里"`lower().split()` 导致中文失效"的细节 | 未核实原文；如果你要用这个说法，先自己打开教程确认，或者干脆不提 |
| 任何只有"某 AI 说"、没有链接和编号的论文 | 无法核验，一律不用 |
| 把 CRAG 扩展版的"自主 agent"表述当作 CRAG 原论文结论 | 与 arXiv 原文口径不一致，容易被追问 |
